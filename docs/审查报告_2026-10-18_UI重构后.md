## 六、打包过程中的事故与恢复（如实记录）

在替换产物时，一条 PowerShell 命令里连着写了"移动旧包 → 移动新包 → 删除旧包"，
第二步因路径不存在失败（PowerShell 非终止错误），**后续删除语句继续执行**，
导致 `dist` 与 `dist_new` 两份 17.3GB 产物同时被删；更棘手的是源码里的
`gguf_models` 早前按需求清理过，PyInstaller 随即报"缺少 10 个模型文件"。

恢复过程：

1. 意识到 Ollama 安装模型时把**同一份 GGUF** 存进了
   `%USERPROFILE%\.ollama\models\blobs\sha256-*`。
2. 新增 `chatui/restore_gguf.py`：对 `ollama show <model> --modelfile` 取 `FROM` 路径，
   校验文件头 `GGUF` magic 后拷回 `chatui/gguf_models/`；视觉模型额外还原 `mmproj`。
   实测 11 个文件全部还原（17.7GB，未重新下载）。
3. `prepare_bundle.py` 重算 sha256 与 Modelfile → 清单 10 个模型校验一致。
4. 重新打包 → `verify_dist.py` 全绿。

教训（已写进操作习惯）：

- 破坏性命令**一步一条**，每步先断言再执行；不要用 `if (...) { 移动; 删除 }` 串联。
- 交付产物与源权重至少有**两份**独立副本，否则一次误删就没有回滚点。
