【离线AI聊天工具 · 彻底卸载 / 清痕工具 v3】

本版更新（相对旧版）：
· 路径里带 空格、中文、( )、& 等字符也不会再出错（旧版会报"不是内部或外部命令/
  内存资源不足"，本版已彻底修复）；
· 不需要再把脚本放进 offline_chat 文件夹——直接双击，它会自动找到程序目录
  （本文件旁边、上一两级、桌面/下载/文档、各盘根目录的 offline_chat 都会找）；
· 找不到时会请你把 offline_chat 文件夹拖进黑窗口（或输入路径）；
· 删除全部成功后自动清理日志；若有残留会保留 uninstall_log.txt 方便回传定位。

—— 使用方法 ——
1. 直接双击 uninstall_offline_chat.bat。
2. 核对它列出的【将要永久删除】清单：
   [1] 程序文件夹（含约 14GB 内置模型）      [5] 额外模型目录（若有）
   [2] 便携版 ollama 副本                    [6] ollama 日志
   [3] C 盘模型库                            [7] OLLAMA_MODELS 环境变量
   [4] 程序所在盘模型库（如 D:\ollama_models） [8] 桌面/开始菜单快捷方式
3. 输入 Y 回车开始删除。
   · 若脚本在程序文件夹里面，会弹出一个新黑窗口收尾（删文件夹本身），属正常现象；
   · 若提示找不到程序目录，把 offline_chat 文件夹拖进窗口按回车即可。
4. 看结果清单：[ok] = 已清除；[X ] = 有残留（关闭相关窗口、重启后再跑一次；
   实在不行可手动删除整个 offline_chat 文件夹，它只是普通文件夹）。
5. 完成后重启（或注销再登录）一次，让环境变量变更彻底生效。

—— 安全特性 ——
· 删除前有 Y/N 确认；删除是永久的，不进回收站。
· 若检测到你电脑上另装了官方 Ollama，会自动跳过官方模型库（C:\Users\你\.ollama）
  与其日志，避免误删你自己的模型。
· 无人值守（跳过确认）：先执行 set UC_YES=1 再运行。

—— 失败时 ——
把脚本旁边的 uninstall_log.txt 发回给发送人即可定位。
